Core Pillars

Built for Modern Engineering Teams

Lightweight runtime footprint, framework-agnostic architecture, and privacy-first engineering.

🛡️

Privacy-First Engine

Deeply redacts authorization headers, session cookies, database credentials, JWTs, and AWS tokens before any serialization or display.

⚡

Zero-AI Dependency

100% deterministic heuristic rules engine operates completely offline without network calls, third-party services, or API bills.

⏱️

Chronological Timeline

Bounded ring buffer captures requests, component renders, state mutations, and empty database returns immediately prior to the crash.

🗺️

Original Sourcemaps

Seamlessly maps minified or transpiled stack traces back to original TypeScript source files, displaying exact highlighted code lines.

🧪

Sandbox Fix Verification

Tests generated unified patches against syntax checks and re-evaluates the failure scenario in isolation without touching production code.

🧠

Optional AI Layer

Opt-in multi-provider AI support (OpenAI, Google Gemini, Anthropic Claude) with strictly sanitized payloads for augmented reasoning.

Ecosystem

Universal Framework Adapters

Dedicated npm packages for every major modern runtime.

@whatitbroke/node

Hooks into uncaughtException and unhandledRejection. Features Express HTTP middleware and SQL null query detectors.

npm install @whatitbroke/node

@whatitbroke/react

<WhatItBrokeBoundary> error boundary component, root-to-leaf component render path tracing, and hook rule violations.

npm install @whatitbroke/react

@whatitbroke/vue

Vue 3 plugin with app.config.errorHandler integration, setup function inspection, and reactive prop destructuring warnings.

npm install @whatitbroke/vue

@whatitbroke/angular

WhatItBrokeErrorHandler implementing Angular's ErrorHandler, diagnosing NullInjectorError and circular DI.

npm install @whatitbroke/angular

@whatitbroke/core

Framework-agnostic core engine, universal stack parser, sourcemap extractor, timeline ring buffer, and HTML reporter.

npm install @whatitbroke/core

whatitbroke (CLI)

The global command-line debugger for diagnostics, crash log analysis, sandbox fix verification, and HTML export.

npm install -g whatitbroke
